# Sena Colectivo publication taxonomy

## Purpose

The site is not only a portfolio. It is a publication and evidence system.

Every serious research package should be navigable, inspectable, printable, and eventually bilingual.

## Standard package shape

Each package should use this spine:

1. Hub
   - overview
   - package status
   - version history
   - audience links
   - downloads when final

2. Public brief
   - readable public article
   - concise framing
   - low jargon
   - social-share ready

3. Longform / periodical version
   - deeper context
   - charts and figures
   - source notes
   - print-friendly layout

4. Policy or political-economics brief
   - public leverage
   - governance implications
   - risks and tradeoffs
   - action points

5. Evidence spine
   - sources
   - assumptions
   - calculations
   - definitions
   - caveats
   - provenance

6. Bilingual set
   - reviewed English and Spanish versions
   - no default mixed-language mode
   - static EN/ES routes for SEO-critical pages

## Status labels

Use clear status language:

- Draft
- Source review
- Design review
- Bilingual review
- Final
- Archived
