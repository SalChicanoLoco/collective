# Monetization Packet — SFBC KV1

## Positioning

Do not sell this as an AI miracle. Sell it as relief for overworked owners, managers, and media staff.

## The paid first ask

Offer a paid discovery sprint, not a giant rebuild.

### Option A — 7-day friction audit: $1,500

Deliverables:

- Manager workflow map.
- Website/content update map.
- BrewOS protection checklist.
- Warehouse slotting observation notes.
- Long-bar lighting/service visibility notes.
- One-page priority roadmap.

Best when they want a low-risk start.

### Option B — 14-day prototype sprint: $3,500

Deliverables:

- Everything in Option A.
- Static HTTPS demo customized with their approved photos/copy.
- Jenna media workflow prototype.
- Event-to-site/social/email template system.
- Basic manager cockpit mockup.
- Security and deployment packet.

Best first close.

### Option C — 30-day implementation pilot: $7,500

Deliverables:

- Public site staging refresh.
- Content model for beers, events, venues, and media assets.
- Raspberry Pi sensor proof-of-concept plan.
- Warehouse slotting prototype spreadsheet/dashboard.
- BrewOS backup/isolation plan.
- Staff handoff workflow.

Use only if they ask for the larger path.

## Monthly support

After the pilot:

- $750/month: light support and monthly updates.
- $1,500/month: media/event workflow support and dashboard improvements.
- $2,500/month: ops, security, reporting, and automation support.

## First invoice language

"SFBC exploratory operations and web workflow sprint — static HTTPS demo, workflow audit, and security/ops roadmap. No payment processing, no POS replacement, and no customer surveillance included."

## Suggested closing line

"Rather than guess at a big project, I’d like to start with a paid sprint. Give me one week to map the friction and two weeks if you want a working prototype your team can actually react to."
