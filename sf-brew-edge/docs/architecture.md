# Architecture

Santa Fe Brew Edge is a POS-adjacent edge cockpit with local simulation mode.

## Core model
- Intake compiler: converts pain points into priorities/risk settings.
- Rules engine: deterministic promo/service suggestions.
- Staff UX: one-tap event signaling during rush.

## Future adapters
- POS read-only adapter
- Payment processor reference adapter
- Inventory/keg adapter
- Marketing/event adapter
- Dashboard/reporting adapter
